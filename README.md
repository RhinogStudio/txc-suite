# TXC Suite

Free browser-based tools for working with UK TransXChange timetable files.

- **TXC Viewer** — inspect combined timetables, journey codes and destinations.
- **TXC Date Tool** — review and batch-change operating dates.
- **TXC Validator** — check expiry dates and common data-quality problems.

The tools process selected files locally in the browser. Files are not uploaded to Rhinog Studio or GitHub.

Current suite build: **2026.09.10.1**. See [CHANGELOG.txt](CHANGELOG.txt) for release history.
